### 👋 Привет! Я делаю так, чтобы LLM работали в проде, а не галлюцинировали в демо.

Я LLMOps-инженер: проектирую отказоустойчивые RAG-архитектуры, сравниваю векторные БД под нагрузкой и собираю локальные AI-пайплайны без слива данных в облако.

🔭 **Что я разбираю:**
- 🧠 RAG и GraphRAG, которые не врут на таблицах и финансах
- ⚖️ Qdrant vs Milvus vs Weaviate: бенчмарки, RAM, p99 latency
- 🧩 Каскадные архитектуры: роутинг запросов + models-as-critics
- 🖥️ Локальный стек: Ollama + Neo4j + LangChain + LlamaParse
